# Projeto Countext
* Projeto: Aplicação web de analisador de texto.<br>
* Nome do projeto: Countext.<br>
* Desenvolvedor: Eliseu Nóbrega.<br>
* Propósito:<br>
Propor ao usuário uma aplicação web simples, bonita e que possa analisar seu texto em tempo real.<br>
* Status: Finalizado.

***

**O que o projeto propõe?**:
* Uma aplicação web com visual simples e intuitivo com analise de caracteres, sentenças, palavras, densidade de letras no texto e remoção de espaços

**Estruturação do site**:

* Header com a logo da aplicação e opção de troca de tema

* Titulo seguido de textarea par digitar ou colar texto

* Analises do texto:
  * Opção de remover espaços
  * Contagem de caracteres
  * Contagem de palavras
  * Contagem de sentenças
  * Densidade de letras no texto
